To run the HCV CTC AnyLogic model: 
1. Download the latest version of AnyLogic software via https://www.anylogic.com/
2. Open HCVCTC.alp in the software
3. Under the main menu, navigate to Simulation:main, click the Run bottom, the simulation should start to run
4. The parameters were set to the NO.6 parameter combination in Table 2, as the default parameter sets to start the simulation

During the simulation, one would see the lime green represents susceptible cells in contact with infected cells, the dark green represent susceptible cells, and the red represents infected cells. The yellow
outline shows the first cell infected in the foci, the foci origin. Infected cells are not allowed to proliferate and thus remain undivided. The white represents empty space, which healthy cells (lime green 
and dark green) may proliferate into. Healthy cells may also proliferate and subdivide into two, three, and four smaller cells.

Note: During the first 17 hours,infection of cells by free virus in the media is allowed. Thereafter cells can only be infected by cell-to-cell spread.
